# 🌾 Mandi-Mitra — Frontend Application

React 19 + Vite client application for the **Mandi-Mitra Agricultural Marketing & Market Intelligence Platform**.

## 🚀 Features

- **Figma Design System**: Tailored typography, rich agricultural color palette, and curated photography.
- **Instant Pill Navigation**: Direct, non-jumping active selection with instantaneous section jumps.
- **Price Discovery Search**: Dynamic queries against AGMARK database with immediate price spread analytics.
- **Commodity Market Pulse & Arbitrage Calculator**: Live benchmark rate comparisons and gross profit gain simulation.
- **Interactive Analytics Dashboard**: Powered by Chart.js with Crop and APMC deep-dives.

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start Vite dev server on http://localhost:5173
npm run dev

# Build for production
npm run build

# Lint code
npm run lint
```

## ⚙️ Configuration

Copy `.env.example` to `.env`:

```env
VITE_API_BASE_URL=http://localhost:5000
```
